# Leads-Tracker-Extension
A Chrome extension for saving and managing useful links and active browser tabs. 
Tech Stack: HTML, CSS, Vanilla JavaScript, Chrome Extension API, localStorage
Features-
Save custom URLs manually
Save the currently active browser tab
Store data using localStorage
Open saved links in a new tab
Persistent data even after browser refresh
Simple and clean UI

How It Works-
1. Saving Manual Inputs
2. Saving Current Browser Tab
3. Using localStorage
4. Rendering Leads on the Page

The extension uses a manifest.json file with Manifest Version 3.

If you want to use the extension---->
Clone the repository
Open Chrome and go to: chrome://extensions
Enable Developer Mode
Click Load Unpacked
Select the project folder
The extension is ready to use
